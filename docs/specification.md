# AviUtl2 MCP Phase 0 仕様書（ドラフト）

## 1. 文書状態

- フェーズ: Phase 0 仕様策定
- 状態: 2026-07-18 ユーザー承認済み
- 対象: 初期リリース（V1）と、SDK 実機検証を必要とする拡張候補

本書は Phase 0 の承認内容を記録する。Phase 1 の要件定義で受け入れ基準を確定し、実装開始前に設計承認を得る。

## 2. 目的

MCP 対応AIクライアントから、現在起動している AviUtl ExEdit2 のプロジェクトを安全に参照・編集できるようにする。

PSDToolKit2 と GCMZDrops を利用する制作環境を前提とし、通常のタイムライン編集だけでなく、PSD キャラクター、音声、字幕を扱うワークフローも自動化する。また、接続状態と AviUtl2 ログを取得し、自動デバッグを可能にする。

## 3. 想定ユーザー

- AviUtl2 で動画を制作し、AIに編集作業を委任したい利用者
- PSDToolKit2 で立ち絵、表情、目パチ、口パク、字幕を扱う利用者
- MCPツールの失敗原因をログと状態情報から切り分けたい開発者

## 4. ユーザーストーリー

1. 利用者として、AIに現在のシーン、レイヤー、オブジェクト構成を説明させたい。
2. 利用者として、素材を指定位置へ追加し、移動、名称変更、削除、設定変更を行わせたい。
3. 利用者として、PSD ファイルと音声を追加し、PSDToolKit2 のキャラクターID、表情、目パチ、口パク、字幕設定を操作させたい。
4. 利用者として、編集前に変更内容を確認し、複数操作を1回の Undo で戻したい。
5. 利用者として、指定フレームのプレビューと操作後の状態を比較したい。
6. 開発者として、AviUtl2、ブリッジ、PSDToolKit2、GCMZDrops、MCP のどこで失敗したか診断したい。

## 5. V1 機能仕様

### 5.1 接続・能力・診断

- MCP サーバー、AviUtl2 ブリッジ、AviUtl2 の疎通確認
- AviUtl2、ブリッジ、PSDToolKit2、GCMZDrops の検出結果とバージョン取得
- 現在の編集状態（編集中、再生中、出力中）取得
- 利用可能な操作能力の一覧取得
- AviUtl2 の直近ログ取得と、既知エラーパターンの分類
- タイムアウト、キャンセル、相関ID付き構造化エラー

### 5.2 プロジェクト・シーン参照

- プロジェクトファイルパス取得
- 現在のシーンID、名称、解像度、フレームレート、音声サンプリングレート取得
- 現在フレーム、選択レイヤー、選択範囲、タイムライン表示範囲取得
- プロジェクト未保存状態の識別

### 5.3 タイムライン参照

- レイヤー一覧、名称、表示状態、ロック状態取得
- オブジェクト一覧、位置、長さ、名称、選択状態、エイリアス取得
- オブジェクト内のエフェクト一覧、有効状態、ロック状態、設定項目取得
- トラック値、チェック値、中間区間情報の参照
- エフェクト、エフェクト項目、フォント、パレット、モジュールの列挙

### 5.4 タイムライン編集

- メディアファイル、エフェクト、オブジェクトエイリアスからのオブジェクト作成
- オブジェクトの移動、削除、名称変更、フォーカス変更
- レイヤーの名称、表示状態、ロック状態変更
- 現在フレーム、選択レイヤー、表示位置、選択範囲変更
- エフェクトと設定項目の値、有効状態、ロック状態変更
- 変更前検証と dry-run
- 1リクエスト内の複数変更を1つの Undo 単位にまとめる
- 期待する編集リビジョンを指定し、古い状態に対する更新を拒否する

### 5.5 PSDToolKit2・GCMZDrops 連携

- PSD/PSB ファイルの投入と `PSDファイル@PSDToolKit` オブジェクト作成
- `最初に置くやつ@PSDToolKit` の作成と配置検証
- `セリフ準備@PSDToolKit` と字幕表示オブジェクトの作成
- WAV/TXT/LAB の組み合わせ検出
- キャラクターID、PSDファイル、レイヤー状態、PSDToolKit2エフェクト設定の取得・更新
- 目パチ、口パク（開閉・あいうえお）、パーツ上書きに必要な設定の検証
- GCMZDrops 外部 API の利用可否、API バージョン、対象インスタンスの診断

PSDToolKit2 の非公開 IPC には依存せず、AviUtl2 SDK が公開するオブジェクト操作と GCMZDrops の公開外部 API を利用する。

### 5.6 プレビュー

- 指定フレームのシーン画像レンダリング
- MCP の画像コンテンツとして返却可能な形式への変換
- 操作前後のプレビュー取得を用いたスモーク検証

### 5.7 MCP インターフェース

- tools: 状態取得、検索、編集、PSDToolKit2操作、プレビュー、診断
- resources: 現在のプロジェクト概要、能力情報、診断情報
- prompts: 安全な編集手順と PSDToolKit2 の標準ワークフロー
- ローカル MCP クライアント向け stdio transport

MCP の標準出力はプロトコル専用とし、ログは標準エラーへ出力する。

## 6. 安全仕様

- 外部から受け取った AviUtl2 オブジェクトハンドルをコールバック終了後まで保持しない。
- オブジェクトはシーン、レイヤー、フレーム、内容シグネチャを組み合わせたロケーターで再解決する。
- 読み取りは AviUtl2 の参照セクション、変更は編集セクション内だけで実行する。
- 削除や再構築は dry-run 結果と対象情報を返す。
- シーン設定など SDK 上 Undo 非対応の変更は、V1では既定で禁止し、明示的な許可を要求する。
- タイムアウト時に実行結果が不明になる操作には、相関IDと操作後照会を用意する。
- 名前付きパイプは現在の Windows ユーザーにアクセスを限定する。
- MCP サーバーは任意コマンド実行機能を公開しない。

## 7. 自動デバッグ・テスト仕様

- MCPサーバーの入力検証、ツール処理、エラー変換の単体テスト
- AviUtl2 SDK を模したテストダブルによるブリッジ単体テスト
- 名前付きパイプの接続、再接続、タイムアウト、キャンセルの統合テスト
- MCPクライアントから tools/list と代表的な tool call を行うスモークテスト
- GCMZDrops 共有メモリの状態取得テスト
- 専用の一時プロジェクトを使う AviUtl2 実機テスト
- オブジェクト追加、取得、変更、Undo、削除後の状態比較
- 指定フレームのプレビュー取得と非空画像検証
- AviUtl2 と PSDToolKit2 のログ収集

実機テストはユーザーの既存制作プロジェクトを変更せず、テスト専用プロジェクトで行う。

## 8. SDK 実機検証が必要な拡張候補

公開 SDK に直接対応する関数が確認できていないため、次の機能は安全な実現方法を実機で確認する。UI 自動操作だけを根拠に正式機能とはしない。

- プロジェクトの新規作成、開く、保存、別名保存
- プレビューの再生開始、停止
- 既存オブジェクトへのエフェクト追加、削除、並べ替え
- オブジェクト分割、長さ変更、区間・キーフレームの直接編集
- シーンの追加、削除、切り替え
- 出力プロファイル選択とレンダリング開始・進捗取得

代替案としてオブジェクトエイリアスの再構築を検証するが、対象の置換、設定保持、Undo、安全性を証明できない場合は採用しない。

## 9. 制約

- AviUtl2、SDK、PSDToolKit2 は更新途上であり、バージョン差異を能力情報として扱う必要がある。
- GCMZDrops 外部 API は最初に起動した AviUtl2 インスタンスでのみ利用できる。
- AviUtl2 SDK の編集関数はメインスレッドの編集コールバック内で実行する必要がある。
- 現在の環境には .NET SDK、Node.js、Visual Studio C++ ツールチェーンが導入されている。
- GitHub リポジトリは public とし、MIT License を適用する。

## 11. 敵対的レビュー結果

### 解消済み

- SDKハンドルを安定IDとして公開すると無効参照になる問題を、リクエストごとの再解決方式へ変更した。
- IPCスレッドから直接 AviUtl2 編集関数を呼ぶデッドロックリスクを、編集コールバックへのディスパッチ要件として明記した。
- SDK非対応機能を実装可能と断定していた問題を、実機検証が必要な拡張候補へ分離した。
- PSDToolKit2 の内部実装へ密結合するリスクを避け、公開された AviUtl2 SDK と GCMZDrops API を境界とした。
- ユーザーの制作プロジェクトを自動テストで破損するリスクを避け、専用プロジェクトだけを使用する仕様にした。

### Phase 1で具体化する事項

- V1の個別MCPツール名、入力スキーマ、出力スキーマ
- 安定ロケーターと編集リビジョンの算出方法
- 1操作あたりのタイムアウトと最大応答サイズ
- PSDToolKit2の各設定項目に対する受け入れ基準
- 実機テストで使用する AviUtl2 実行ファイルとテスト素材
